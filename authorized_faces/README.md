# Fotos autorizadas

Coloca aquí las fotos de referencia de las personas autorizadas.

- Usa una foto clara por persona.
- Formato recomendado: `.jpg` o `.png`.
- Nombra el archivo con el DNI, por ejemplo: `12345678.jpg`.
- No guardes datos personales en el nombre del archivo.

El registro completo debe hacerse desde la sección de imagen para guardar también nombre, apellido, edad, DNI y teléfono en Supabase. DeepFace utiliza la imagen almacenada en Supabase para verificar la identidad.

Esta carpeta no se publica automáticamente ni reemplaza el bucket privado de Supabase.
